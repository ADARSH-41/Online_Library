# Online Library

Online Library is a web-based application developed to manage and access library resources digitally.
The application allows users to browse available books and manage library-related information.
It is built using Java and the Spring MVC framework.
The project uses JDBC and `JdbcTemplate` for database connectivity and data operations.
Spring configuration files are used to manage application components and dependencies.
The application follows a layered architecture for better organization and maintainability.
Database changes and schema management are handled using Liquibase.
The project is deployed and tested on an Apache Tomcat server.
The user interface is integrated with the backend through Spring MVC controllers and views.
This project demonstrates practical implementation of Java web development, database integration, and Spring-based application development.

If you want to try this project, just checkout the project on your local machine with java 23 installed and configured to the Path variable.
Download apache tomcat server with version 11 and after building the maven project add the deployment war file to the server and start.
